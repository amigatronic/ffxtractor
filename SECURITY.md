# Security Policy

## Supported version

The current development version documented by the repository is v7.

## Reporting a security issue

Do not publish sensitive security issues as public GitHub issues.

Use GitHub's private security reporting mechanism for the repository when available.

When reporting an issue, include:

- a concise description;
- reproduction steps;
- the affected version;
- the expected behavior;
- the observed behavior;
- relevant logs with private paths or sensitive information removed.

## Scope

FFxtractor executes locally installed FFmpeg and FFprobe binaries and passes user-selected media paths and generated arguments to them.

Only use trusted FFmpeg/FFprobe binaries and keep them updated according to the security practices of your environment.
